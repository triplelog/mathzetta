# Security

MathZetta's libraries read input that is often untrusted: maths typed into pages, stored in
documents, carried in links. If you find a way for an input to run code, reach data it shouldn't,
break out of generated JavaScript, Python, SQL or spreadsheet formulas, or hang a page, please tell
me privately first:

**rwilcox@mathzetta.com**

Include the input, the function you called and what happened. I'll reply within a few days, fix
it in a release, and credit you if you'd like.

Supported: the latest release of each package (`mathzetta` 1.x; `@mathzetta/inlinemath` and `@mathzetta/cas` once
published).
